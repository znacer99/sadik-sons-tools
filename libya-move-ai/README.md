### نظرة عامة على المشروع (Executive Overview)
**LIBYA MOVE AI** هي أول منصة ليبية متكاملة لتقنيات التنقل (Mobility Technology Super-Platform) والبنية التحتية الرقمية، تبدأ من **طرابلس الكبرى** وتتوسع تدريجياً إلى **مصراتة، بنغازي، وباقي المدن الليبية**. 
المشروع مبني على نموذج **Asset-Light** متطور يجمع بين:
1. **منظومة الركاب الحضرية**: مع ميزة **Move Choice** للاختيار الذاتي للسائق.
2. **بوابة السائق المحترف (Move Driver Pro)**: المعززة بخوارزمية **Smart Return Ride** لتقليل الكيلومترات الفارغة بنسبة 80% وزيادة دخل السائق بنسبة 40%.
3. **حلول المؤسسات والشركات (Move Business)**: إدارة تنقل الموظفين بحصص استهلاك رقمية وفواتير ضريبية موحدة تلغي المعاملات النقدية غير الموثقة.
4. **برمجيات إدارة الأساطيل (Move Fleet SaaS)**: تتبع استهلاك الوقود والسرعة ومواعيد الصيانة الدورية.
5. **محرك الذكاء الاصطناعي وغرفة العمليات (Tripoli AI Ops Center)**: التنبؤ بالطلب والتسعير الديناميكي وإدارة الأمان عبر رمز PIN اللحظي.
